## ⚠️ 已知问题

### 1. AkShare 连接失败
**问题**: AkShare 提供器连接测试失败  
**错误**: `RemoteDisconnected('Remote end closed connection without response')`  
**原因**: AkShare 网站反爬虫机制或网络波动  
**影响**: 低（有其他 3 个数据源可用）  
**解决方案**: 
- 增加重试次数
- 添加请求头模拟浏览器
- 使用备用接口

### 2. BaoStock 列名不一致
**问题**: BaoStock 返回的 DataFrame 列名与其他提供器不一致  
**影响**: 低（统一数据服务层会自动处理）  
**解决方案**: 在 BaoStockProvider 中添加列名映射

## 🔧 修复记录

### 修复 1: Tushare 获取股票基本信息返回空数据
**问题**: `get_stock_basic()` 返回空 DataFrame  
**根因**: 查询参数中包含 `exchange` 导致 API 返回空  
**修复**: 移除 `exchange` 参数，只使用 `ts_code`  
**验证**: ✅ 测试通过

### 修复 2: 查询参数优化
**问题**: 获取所有股票时未指定参数导致返回过多数据  
**修复**: 添加默认参数 `exchange=''` 和 `list_status='L'`  
**验证**: ✅ 测试通过

## 📝 使用示例

### 基础使用
```python
from stock_data_service import StockDataClient

# 创建客户端
client = StockDataClient()

# 获取股票基本信息
df = client.get_stock_basic("000001.SZ")

# 获取日线数据
df = client.get_daily_data("000001.SZ", start_date="20240301")
```

### 自定义配置
```python
from stock_data_service import StockDataConfig, StockDataClient

# 自定义配置
config = StockDataConfig(
    tushare_token="your_token",
    tushare_gateway="http://your-gateway.com",
    cache_enabled=True,
    data_source_priority=["tushare", "akshare"],
)

# 使用自定义配置
client = StockDataClient(config)
```

### 查看统计
```python
# 提供器统计
provider_stats = client.get_provider_stats()

# 客户端统计
client_stats = client.get_client_stats()
```
